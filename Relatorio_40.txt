4. IMPLEMENTAÇÃO
================================================================================

Comportamento:
- Prestador navega para "Minhas Coletas" → seleciona coleta EM_CONFERENCIA
  → detalhe exibe botão "Abrir conferência"
- Ao tocar, navega para TelaPrestadorConferencia
- Tela carrega itens declarados via iniciarConferencia (POST)
- Prestador registra pneus individualmente: DOT, marca, medida, nº fogo
  (ou marca como ilegível)
- Cada pneu é adicionado à lista local com validação UX
- "Registrar pneu(s)" agenda no Outbox (funciona offline)
- "Concluir conferência" agenda conclusão no Outbox
- SnackBar confirma cada ação
- Backend revalida tudo no processamento do Outbox

Backend não alterado. Firestore não utilizado. Dependências não adicionadas.
