3. IMPLEMENTACAO:

3.1. api_service.dart:
- Typedef EnviarLeitura: Future<RespostaHttp> Function(caminho, cabecalhos)
  (reutiliza RespostaHttp do servico_sessao.dart).
- ApiService com construtor injetavel (enviar, baseUrl, obterToken).
- listarMinhasColetas() → GET /api/v1/collections → List<Map<String, dynamic>>
  * CLIENTE: retorna proprias coletas; PRESTADOR: retorna atribuidas.
- obterColeta(id) → GET /api/v1/collections/{id} → Map<String, dynamic>
  * Somente CLIENTE; 404 uniforme (anti-enumeration).
- listarDisponiveis() → GET /api/v1/collections/disponiveis → List<Map<String, dynamic>>
  * Somente PRESTADOR; coletas SOLICITADA sem provider.
- _get(): metodo privado que monta cabecalhos, envia Authorization Bearer
  quando token disponivel, trata HTTP != 200 como Exception.
- _getViaHttp(): fallback HTTP real via package:http (http.get).
- Transporte HTTP injetavel para testes sem servidor.

3.2. Tratamento de erros:
- HTTP 200: parse JSON e retorna dados.
- Qualquer HTTP != 200: throw Exception('Erro HTTP $codigo').
- Excecao de rede: propaga (throw).
- Nao cria mecanismo paralelo; segue o padrao existente.
