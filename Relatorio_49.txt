## 1. RESUMO EXECUTIVO

Implementado o cancelamento de coleta pelo CLIENTE usando o endpoint **já existente** no backend:

**Backend Contract:**
- `POST /api/v1/collections/{coleta_id}/cancelar`
- Auth: CLIENTE role required
- Payload: `{}` (corpo vazio)
- Transição permitida: **apenas `SOLICITADA` → `CANCELADA`**
- Retorna: `{id, status}` com `status = "CANCELADA"`
- Erros: 401, 403, 404, 409 (transição inválida)

## 3. CONTRATO HTTP UTILIZADO

```
POST /api/v1/collections/{coleta_id}/cancelar
Headers:
  Content-Type: application/json
  Authorization: Bearer <token>
Body: {}
Response 200: { "id": "...", "status": "CANCELADA" }
Errors: 401, 403, 404, 409
```

**Regra de status:** Somente `SOLICITADA` → `CANCELADA` permitida. Outros estados retornam 409.
